# Индикатор комментария/разметки в дереве вариаций — дизайн-спек

## Контекст

Ручная SGF-разметка (комментарии + фигуры/метки `TR`/`SQ`/`CR`/`MA`/`LB`, ветка `feature-sgf-annotation`, смёржена в `main`) только что прошла ручную приёмку. Пользователь предложил небольшое улучшение сразу после приёмки: в дереве вариаций (`frontend/src/renderer/src/board/VariationTree.tsx`) визуально показывать, у каких узлов есть комментарий и/или разметка — не только у текущего, а у любого хода, чтобы было видно, где вообще есть доп. информация, не листая туда-обратно.

Небольшое UI-улучшение к уже принятой фиче, не новая подсистема. Явно запрошено пользователем.

## Scope

- Один комбинированный индикатор на узел: «есть комментарий ИЛИ разметка» — без различения типа.
- Работает для любого узла дерева, включая корень.
- Никакого нового состояния, IPC или мутации — чистая функция от уже доступного `node.data` в существующем компоненте.

Вне скоупа: отдельные индикаторы для комментария и для разметки; клик по индикатору с переходом сразу на вкладку «Разметка» (можно рассмотреть отдельно в будущем, если понадобится).

## Дизайн

**Логика проверки** (новая чистая функция, например `hasAnnotation(node: NodeObject): boolean` в `VariationTree.tsx`):
```ts
function hasAnnotation(node: NodeObject): boolean {
  if (node.data.C?.[0]) return true
  return ['TR', 'SQ', 'CR', 'MA', 'LB'].some((key) => (node.data[key]?.length ?? 0) > 0)
}
```

**Рендер:** в существующей `renderMarker(node)` — если `hasAnnotation(node)`, внутрь кнопки `.variation-tree__marker` добавляется маленький SVG-треугольник (уже есть прецедент такой SVG-разметки в проекте — `@sabaki/shudan`'s `Marker.js` triangle path `M 0 .5 L .6 .5 L .3 0 z` в `viewBox="0 0 1 1"`, используем тот же паттерн для консистентности с уже нарисованными на доске треугольниками). Кнопка остаётся тем же элементом, тем же размером — треугольник просто один из дочерних узлов внутри неё.

**Цвет:** `fill: var(--color-accent, #22C55E)` — акцентный зелёный, уже принятый в design-tokens проекта (`docs/ARCHITECTURE.md` § UI/UX-принципы фронтенда), используется для позитивного winrate. Читается на чёрном/белом/прозрачном (root) фоне кружка без дополнительной подложки.

**CSS:** новый класс `.variation-tree__marker-annotation-icon` (позиционируется `position: absolute` внутри `.variation-tree__marker`, который уже должен получить `position: relative` — сейчас его нет, добавляется как часть этой правки).

## Тестирование

Компонентный тест в стиле уже существующих (`frontend/tests/renderer/components/VariationTree.test.tsx`): узел с `C[]` показывает индикатор, узел с `TR[]` показывает индикатор, узел без того и другого — не показывает, узел с пустым `C[]` (после `setComment(tree, id, '')`, ключ удаляется) — не показывает.

## Критерии готовности

- Открыть партию с разметкой/комментариями на нескольких узлах (например, тот же тестовый SGF, что использовался при ручной приёмке) — индикатор виден на всех узлах с доп. информацией и не виден на остальных, независимо от текущей позиции в дереве.
